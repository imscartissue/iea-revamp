# 02 — Design system

Source of truth: `src/styles/index.css` (Tailwind v4, `@theme inline` aliases
over CSS variables, so the `.dark` override rethemes everything).
Fonts: `src/styles/fonts.css` (generated by `scripts/build-fonts.mjs`).

## Type scale

Each `type-*` utility carries its own font family. Serif = reading, sans =
operating, numerals tabular. Only weights 400 and 700 exist.

| `type-display` | serif 700 | `clamp(2.75rem,7vw,5.5rem)` / 0.95 — one per page |

| `type-heading` | serif 700 | `clamp(1.25rem,2vw,1.5rem)` / 1.2 |
| `type-subheading` | serif | 1.0625rem / 1.6 |

Helpers: `measure` (68ch), `measure-tight` (60ch), `measure-snug` (48ch),
`defer-paint` (below-fold `content-visibility`).

## Shape, shadow, motion

- Radius: `sm 2px`, `md 4px`, `lg 8px`. Sharp by default; only floating
  surfaces get 8px.
- Only three shadows: sticky header, sheet/dialog, mobile filter drawer.
- Motion is transform/opacity-only CSS: `--ease-brand
  cubic-bezier(0.16,1,0.3,1)`. No animation library. A global
  `prefers-reduced-motion` rule disables animation; `useReducedMotion()` lets
  components skip (not shorten) things like the intro.

## Dark mode and fonts

- Class-based (`@custom-variant dark`). An inline script in `index.html` reads
  `localStorage("iea-theme")` before first paint, so no flash. Default with
  nothing stored is **light**, not OS-following; "System" is opt-in.
- Latin Modern Roman (reading) + Latin Modern Sans (UI), 400/700 only, woff2,
  `font-display: swap`. Only the two above-fold faces are preloaded.
- Base: `h1–h4` serif with `font-style: normal` (no faux italic),
  `:focus-visible` 2px bronze outline, bronze-soft selection.
